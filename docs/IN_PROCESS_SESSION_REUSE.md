# 连续查询复用当前采集会话

本功能直接承接 #49 登录后自动取数，并覆盖 #50 中**同进程会话连续性**的一部分。
它不实现自动填写密码、跨进程保存登录状态或真实平台登录认证。

## 操作

在程序弹出的采集浏览器中正常登录，完成列表读取或当前采集批次。
后续任务在第2步勾选“复用当前空闲采集浏览器的同平台会话”，填写新关键词并开始。
兼容时直接使用同一个浏览器上下文打开新查询，保留网站自己的内存会话；不重复登录、
不导出 Cookie、不复制到日常浏览器。没有现有浏览器时，第一次任务正常启动新的浏览器。

原任务的候选、选择和报告保留，新任务单独记录自己的结果、报告和会话来源任务编号。
读取到岗位列表只证明页面可读，并不证明某个账号已经认证。平台要求重新登录或人工验证时，
继续走原平台登录/人工接管流程；不会因为选择“复用”就跳过该验证。

## 范围与停止

仅复用同一工作区、同一程序运行、同平台、同后端、同浏览器、同网络策略的存活会话。
前一任务必须处于列表就绪或已完成状态。登录中、限流中、拒绝或其他终止错误不会被新任务接管；
不创建新浏览器规避失败。配额保持共享，不重新计零。

勾选后发现条件不符会说明原因，旧窗口保持；用户可回原任务完成登录或明确停止。
新任务接管后，只有新任务的“停止并关闭登录会话”会关闭该浏览器，旧任务的停止操作不会误关新任务。
退出程序或关闭采集会话后无法复用，重启后仍须正常登录。#50 的持久会话与正常自动表单登录未由本功能交付。

## 验证

定向单测覆盖显式选择、工作区/平台/后端/网络隔离、暂停/拒绝、活跃登录、已关闭浏览器、
进度回调重新绑定、原报告不变和停止所有权。
现有浏览器验收另加完整链路：正常人工登录 → 自动接续列表 → 详情/报告 → 新查询复用同一浏览器 →
不增加登录POST → 新批详情/报告 → 停止关闭。
所有自动化样本均为人工测试数据；真实猎聘的登录、搜索和必要资源契约仍须正常会话现场验证，
不能用这些测试宣布 #49 的真实完整JD门槛完成。
