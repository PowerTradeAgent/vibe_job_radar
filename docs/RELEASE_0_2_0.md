# 0.2.0 发布候选说明

关联工程 Issue #14，总路线 #3/#9。版本号用于本次PR候选构建；只有合并与正式标签发布后才称为正式发行。

## 用户可见变化

首页新增 `/guided` 向导：平台和关键词输入、站内列表发现、自动汇总详情链接、勾选正文采集、本批报告和CSV直接下载。原高级URL/Search API/JSON源及证据界面保留。

可选真实Chromium采集后端；平台原生页人工登录、人工接管与同一会话后续自动采集。应用不接收账号密码、会话不持久化，不自动接受网站条款、不代投递。

按工作区/站点共享的硬限频与冷却，后台批次任务，暂停/停止/中断提示。页面关闭后当前批次继续，关闭服务后登录状态丢弃；不是常驻定时调度器。

DNS诊断展示真实解析地址，识别198.18.0.0/15提示，不关闭公网检查。依赖安装是明确确认后的固定命令，使用原Python解释器。

## 数据与兼容

新增`guided/`任务及限频数据库；主库、报告和个人证据沿用现有位置。新增`browser_fetch`来源模式，旧代码不保证读取；升级前先停止服务备份整个工作区。不会自动迁移或上传本机浏览器Cookie。

## 发布资格

保留全部原测试并增加协议、解析、状态、共享配额、网络边界、凭据不落盘和HTTP检查。新增双浏览器E2E必须通过，验证动态列表、正常登录、跳转真实URL、入库与报告。

本次内置三站页面配置未完成用户真实账号的实站认证，仍为not_live_verified。公开页面可用性不由受控测试证明，登录/robots/资源域名/DOM差异可能需要逐站迭代。候选源码包不是已经带有Python/Chromium的免安装EXE。

账号密码自动填入原定属于Issue #14，因本轮提交安全检查阻止该实现，收窄为人工原生登录；该项未交付。没有正式创建release/tag，当前为PR候选。
