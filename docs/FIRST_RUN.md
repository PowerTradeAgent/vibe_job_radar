# 从零使用与验收

## 准备

安装 Python 3.10+，完整解压源码。Windows 双击根目录 `start_windows.bat`；macOS/Linux 执行 `python3 scripts/start_workbench.py`。也可运行 `start_macos.command`，文件没有执行权限时先执行 `chmod +x start_macos.command`。

第一次使用仍需要安装 Python；这不是独立 EXE。不要只下载启动脚本，脚本需要同一份源码中的包文件。

## 打开与自检

启动后会显示本地访问地址和数据目录。浏览器未自动打开时，复制终端给出的完整地址（包括 `#token`），不要分享地址。默认系统选择空闲端口；旧书签可能在重启后失效。

点击环境自检，检查 Python、SQLite 和目录写入状态。自检不调用外部服务，也不证明搜索密钥有效。命令行自检为：

```powershell
py -3 scripts/start_workbench.py --doctor
py -3 scripts/start_workbench.py --workspace "D:\Radar Data"
```

macOS/Linux 将 `py -3` 换成 `python3`。无法自动打开浏览器时可使用 `--no-browser`；端口冲突时使用 `--port 0`。

## 实际操作

先运行合成演示。它只写入独立的 `demo.sqlite`，不是市场数据；真实库为 `jobs.sqlite`。

在你自己的招聘网页或 App 查找职位，再将有权处理的文本带入工作台。填写真实标题、平台、来源链接或说明、正文与允许使用范围。完整 JD 才标记为完整正文，搜索片段应保留为摘要。

保存后，选择岗位并生成报告。岗位筛选依据真实标题和正文，不会因为勾选岗位就修改招聘要求。平台复选框仅影响搜索发现；分析按岗位筛选已导入数据。

下载并核对 `requirements_zh.csv` 的逐条原文，查看 `descriptions.md`、`role_descriptions.md`、`evidence_gaps.md`。`review_queue.csv` 是待复核清单，`input_audit.csv` 解释输入为何未纳入，`run_manifest.json` 记录参数、警告与统计。

下载的 `dashboard.html` 可在本机浏览器打开。每次报告独立保存，重启后沿用同一数据目录可查看历史。不要未经检查就公开含原始文本的报告。

## 文件与可选搜索

工作台支持 UTF-8 JSON/JSONL/CSV，最多 1 MB、1000 条。CSV 可使用 `职位名称,公司,平台,来源链接,城市,职位描述` 表头；平台值使用 `boss`、`liepin`、`51job` 等配置标识。全部行先校验，错误时不开始入库；这不是断电或磁盘故障下的事务恢复保证。

TXT、Markdown、HTML 和更大文件沿用原 CLI。它的逐行处理契约没有修改。

在线发现需要自己的 Brave Search API Key，可在工作台填入供本次操作使用，或在启动前设置 `BRAVE_SEARCH_API_KEY`。项目不自动读取 `.env`。先预览搜索计划不会产生请求，执行发现时设置 1～20 次请求预算。

搜索结果仍是摘要。你需要打开来源，在允许使用的范围内补齐完整 JD。没有搜索 Key 也能使用全部本地流程；密钥配置状态不等于联网验收结果。

## 个人量化描述

个人证据与原文复核现在已提供浏览器表单：从首页进入“自动采集 / 证据中心”，选择真实报告、复核原文、上传证据、添加指标、勾选精确要求并生成个人报告。无需手写 JSON，详情见 `docs/WORKFLOWS.md`。原 CLI 的 `--candidate`、`--reviews` 继续兼容。

数据库选择工作台显示的数据目录里的 `jobs.sqlite`，输出目录必须是新的空目录。CLI 另行指定的输出不会自动加入工作台历史列表。

没有本人证据时保持【待填】。指标必须说明基线、当前值、样本量、观测窗口、比较口径、离线或生产阶段。要求覆盖率不是录用概率。

## 停止与排障

Ctrl+C 或关闭终端停止服务。停止后备份完整数据目录，包括 SQLite 相关文件、`imports/`、`reports/` 和 `discovery/`。删除目录会删除本地历史，不要在运行中直接改数据库文件。

Python 未找到时检查安装及版本；目录不可写时改用 `--workspace`；访问失败时重新复制本次启动的完整地址，不要把 `127.0.0.1` 换成别的主机名。

零正文或零要求时检查摘要标记、岗位匹配、采集新鲜度和复核队列，不能由零命中断言市场不存在。搜索失败时核查网络、自己的 Key 与服务配额，不影响离线分析。

本次自动验收使用人工测试数据及模拟外部响应。真实平台账号、真实搜索密钥与实际招聘样本的线上验收尚未完成。工作台是单用户本地程序，不是多人在线服务。
