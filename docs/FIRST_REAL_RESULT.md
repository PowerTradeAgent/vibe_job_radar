对应 Issue #20 / PR #21；本轮合并与清理审计见 Issue #22。统一从 main 下载完整源码，不再依赖临时修复分支。停止旧服务，在新目录操作，不要删除原来的数据目录。

## 不再填一堆字段：运行真实案例

在源码目录的Git Bash终端，复制你已经能用的Python路径运行：

```bash
/d/code_environment/anaconda_all_css/py312/python.exe scripts/run_real_example.py
```

看到“是否获取？”后，输入 **y** 并回车。无需URL、API Key、账号、接口契约、Playwright或Chromium。程序读取一条公开岗位、保存数据、生成报告，并用系统浏览器打开本机报告。不是在终端里只打印一份空状态。

Windows也可双击根目录 **get_real_example_windows.bat**。它优先使用环境变量RADAR_PYTHON，其次py -3/python；使用指定Anaconda环境的人优先用上面的精确命令，不必配置环境变量。

第一次结果出来后，检查页面中的逐条原文。报告目录和CSV路径也会打印到终端。回工作台刷新，即可看到新岗位和这份报告；个人证据仍可通过高级页面编辑。工作台使用自定义目录时，在命令末尾加 `--workspace "实际目录"`，以基础页显示的工作区为准。

默认工作区为用户主目录下 `.vibe-job-radar`。案例不会删除旧数据，也不触发其他历史任务。需要只保存结果不弹网页时加 `--no-browser`；明确同意公开GET与本机保存后可用 `--yes` 跳过确认。

第一次真实联网核对取得8230字符正文、12条提取记录，其中11条规则接受、1条待复核。这是观测值，不是写死返回值，后续可能变化。同一句可映射多个能力，不能把12条记录等同于12条互不重叠的雇主要求；规则接受也不等于人工验证。

十分钟内再次运行会明确复用缓存并保持原获取时间；不假装又联网了。失败时不改用合成数据。职位下架或字段变化后需要维护真实来源，不能保证固定链接永远存在。

## 旧URL任务的两个错误不是一回事

`redirect_not_followed`：旧HTTP路线遇到3xx跳转就停止，没有记录Location。跳转可能发生在robots规则页或职位详情，不能仅凭错误认定“必须登录”。当前匿名HTTP不会继承浏览器Cookie。

`budget_skipped`：这一条尚未执行，正文尝试预算已经用完，不是第二次网络失败。搜索0/24和数据源0/5不参与URL路线。进入report阶段并不等于取得正文。

新版允许有限的正常安全跳转：最多3次，逐跳HTTPS、已许可同平台域名、公网IP、TLS和robots检查。每条职位仍只算一次正文尝试，同时另记HTTP尝试数。最终URL用于正文解析与入库。

登录/验证入口、未许可域名、私网、凭据地址、循环或过多跳转会明确停止；不转发Cookie/Authorization。诊断保存阶段、HTTP状态、来源域名和原因，不记录Location中的查询凭据。高级页逐条显示中文解释和下一步。

新URL批次仅为本批成功/复用记录生成报告。全失败就明确没有结果，不把全库历史岗位拿来冒充本次成功。旧日志缺失的目标不能事后推测，新任务才能记录新诊断。

## 确实需要登录时

在高级页的结果区可以打开“进入浏览器向导”。该入口是现有 `/guided`，不是本次新增了自动填密。按原按钮指南，在平台原生采集浏览器本人登录后继续采集；它不自动继承旧HTTP任务或日常Chrome会话。

本轮原计划的“网页一键实时取数”和“原任务URL自动带入浏览器”需要修改核心HTTP入口；该提交被连接工具阻止，未写入本PR，也没有采用其他工具或编码绕过。已取消相关未连接按钮，改交付以上可运行、会保留报告的本地案例入口。工作台核心HTTP入口保持不变。这两项未交付的界面整合已明确转入 Issue #3 / #9；关闭本期交付 Issue #20 不表示它们已完成。

## 按结果排障

| 结果 | 下一步 |
|---|---|
| 真实案例 dns_error/network_error | 检查公开接口域名的网络；BOSS DNS通过不等于所有来源可达 |
| 真实案例 http_404/example_source_changed | 来源下架或结构变更；没有偷换数据，需维护真实案例 |
| example_processing_failed | 上游或本地处理未完成，查看记录；不反复点击造请求 |
| URL redirect_login_required | 停止匿名HTTP，使用现有原生浏览器人工登录流程 |
| robots_denied/redirect_domain_not_permitted | 不放宽访问规则；改用允许的接口或有权处理的文本 |
| budget_skipped | 先处理已尝试条目的错误，再为未执行链接明确建立小批次 |

真实案例每工作区至少30秒、12请求/小时、24请求/滚动24小时；成功结果10分钟缓存，用户界面不能提高。请求失败也计数，不自动重试。

## 验证口径

离线测试用人工HTML/JSON检查安全跳转、错误与预算解释、报告隔离、取消与命令入口。真实Chromium检查现有工作台读取案例报告、下载CSV和展示旧失败详情，界面测试上游为人工数据。

独立 `python scripts/check_live_public_example.py --live` 才访问真实官方接口，单次GET，生成报告但只输出元数据与计数，不上传全文。它验证真实外部来源，不等于认证BOSS/猎聘/51job。用户正常取数应使用run_real_example.py，测试脚本会清理临时工作区。
