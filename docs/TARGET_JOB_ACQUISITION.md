# 主线：选中的真实岗位不能在采集过程中丢失或被替换

开发起点为用户合并 PR37 后的 `main@270dfc0b9bf769281adaffe82bb866b649c38d69`。目标仍是指定平台的目标岗位正文 → 可追溯要求 → 本人证据，不新增监测平台、服务器、队列或代理协议。

## 本轮发现与修复

### 职位链接被提前过滤

公开搜索索引能观察到猎聘 `/job/<id>.shtml`、`/a/<id>.shtml` 和 `/lptjob/<id>` 三类职位链接；旧适配器只接受第一类。现在保留原 `/job/` 规则，并仅增加后两类的数字 ID 形式。三类均可从原列表进入原正文采集流程。它们也均不被当成搜索列表。域名、HTTPS、凭据参数、TLS、robots、原生登录和额度保护不变，没有新增端点请求能力。

观察出处（公开链接形态，不是实站采集认证）：
- https://www.liepin.com/job/1985181289.shtml
- https://www.liepin.com/a/76685567.shtml
- https://www.liepin.com/lptjob/75416869

本轮再次请求这些页面均进入平台验证页面，随即停止，没有换身份、出口或规避验证。没有取得可用于断言真实 DOM 选择器的 HTML，也没有把索引中的正文复制成测试数据。当前运行容器的本项目 DNS 检查另外返回 `dns_error`。网页工具、容器网络和用户本机的结果是三件事，不能相互代替。

### 正文中的结构化岗位身份

旧解析器遇到多个 JobPosting 就整体拒绝，而单个但明确指向别的岗位的 JobPosting 又可能被错误登记到当前 URL。现在只在可唯一匹配实际来源 URL 时选择目标。支持 `url`、`mainEntityOfPage` 的字符串/页面对象及绝对 URL 或 fragment 形式的 `@id`。保留原单对象无身份信息的兼容路径；多个无身份对象、冲突、错误字段、重复 JSON key、其他岗位或同岗位多版本均停止，不选择“第一个”。不同路径的相同数字 ID 不自动认定为同一岗位。

网址只在内存中比较，绝不访问元数据中的链接；跟踪字段按原项目规则规范化，未知查询参数仍参与身份。原文没有截断成成功，正文类型也不能把数组或字典强行字符串化。普通未使用的 captcha 脚本名称不再让共享解析器误判验证页，实际文本中的验证提示仍拒绝。无整页 body 兜底、无 AI 补写正文。

参考结构化字段定义：https://schema.org/JobPosting 和 https://schema.org/mainEntityOfPage 。这里是有条件的解析支持，不保证任意站点的 structured data 正确，也不单靠哈希声称来源真实性。

### 批次的产品结果

本次所选数量、保存正文、失败、待处理、纳入目标岗位和有正向 AI 编程证据的数量分别呈现。任务线程结束不等于用户研究已完成。

结果状态：`no_data`（零正文）、`no_target`（已保存但不匹配所选岗位）、`no_ai_evidence`（目标正文有，但没有已接收的正向 AI 编程证据）、`analysis_incomplete`、`partial`、`ready`。零 AI 证据不说明市场没有需求。统计来自同批原始分析，不用历史数据库凑数。

一条无法构成 JobRecord 的正文只记 `invalid_job_data`，不再用泛化异常中断后续所有岗位；这不适用于 401/403、验证码、TLS、配额或其他硬失败，原停止行为保持。正文过长不会静默截短。

有部分正文时，报告同时保存 `guided_acquisition.json` 和 manifest 中的 `acquisition_outcome`，记录所选条目的状态和原始/最终链接，并纳入原文件摘要。失败项不会从报告悄悄消失。只有采集报告拥有这个快照；后来的个人报告仍是新的个人分析，不被冒充为新一次采集。零成功不创建虚构岗位报告。没有正文、Cookie、用户名密码、HTTP头或用户授权说明复制进新增审计文件。链接仍是本地数据，分享前须检查。

## 如何开始一次真实使用

保留正常工作的 VPN/TUN，沿用已有解释器启动本次代码和原工作区，不清除限频、历史岗位或登录信息。首页选择一个方向、猎聘、一个正常岗位关键词，按原表单确认实际访问范围，1 页最多 5 条。需要登录时在程序的独立浏览器原生登录，回工作台继续原任务；选择有意义的岗位，再采集。

研究结果达到 `ready` 或 `partial` 且有相关完整正文后，查看要求原文并用本人证据继续。`no_data`、平台拒绝或验证未完成时，不增加预算、反复新建或用固定公开案例冒充。记录当次任务状态/阶段/错误码；不要发送账户密码、Cookie、验证码、完整网络抓包或本地会话令牌。

当前工具无法访问用户的本机正常会话，不能代替这一步。无需等“所有22项功能做完”才试用，但也不预先将三站改为 live_verified。整个实站验收保持 #9 开放。

无数据库迁移或新运行依赖。旧报告不重算，旧 UI 没有 outcome 时仍兼容。回退先停止任务，保留整个工作区、额度与历史报告。后续只修此次真实用户路径中的具体阻断，不新增外围平台。
